# NutriciOS
App web personal de nutrición (PWA, sin backend). Los datos viven solo en el dispositivo; este repositorio contiene únicamente código.
Pruebas del motor: `node engine.test.mjs`.

## Publicar una actualización
Subir `APP_VERSION` en `app.js` y el mismo número en `version.json`; la app muestra el aviso "Nueva versión" y el botón Actualizar.
